# Programmable transfer policy for tokenized real-world assets

Vendor-neutral explainer.

Transfers must fail before value moves when the buyer is ineligible, the wallet is frozen, or the jurisdiction is blocked.

Controls: eligibility, whitelist, freeze, velocity, holding rules, settlement policy, audit log.

Issuer owns the asset relationship. Vendor enforces rules. Custodian holds keys. Vault holds metal.

UnyKorn LLC ships this pattern. Example mandate: Dignity Gold, 17 Aug 2026. UnyKorn is not the DIGau issuer.
